8 File Bạn Đã Gửi (Đã phân tích 100% từng biến vào Web)

Toàn bộ biến [SerializeField], public, struct/class, enum và logic hàm trong 7 file C# cùng file Excel hướng dẫn đã được đưa đầy đủ vào trình mô phỏng Inspector này:

  • 1. StoryEventDirector.cs & StoryEventDirector.Authored.cs
    Bộ điều khiển trung tâm tại Scene, nhận TriggerEvent, mở thoại, xét điều kiện điểm chạy và chạy module.
  • 2. StoryEventAsset.cs
    Định nghĩa file .asset của từng Event, chứa StoryOutcome (35 biến điều kiện/thưởng/chuyển chặng), StoryChoiceOutcome, StoryFlagTest, StoryConditionalEffect.
  • 3. StoryStageDirector.cs
    Quản lý danh sách Chặng (Stages), Đợt quái (Waves), Quy tắc thế giới (LT/QT, Giao kèo, Phase boss), hàm BlockReason() và Apply().
  • 4. StoryEventModules.cs
    10 module lệnh (IStoryAction) và 2 module điều kiện (IStoryCondition) lắp vào danh sách [SerializeReference, SubclassSelector].
  • 5. StoryEventTrigger.cs & 6. StoryFlagBarrier.cs
    Vùng va chạm Collider2D tự gọi Event khi Player bước vào & Rào cản khóa đường khi chưa có cờ.
Các Script Liên Quan (Đã có thông số từ Excel, gửi thêm file .cs nếu muốn soi code)

Nhờ file HuongDan_StoryEventDirector.xlsx bạn đính kèm, mình đã dựng luôn giao diện Unity Inspector đầy đủ các biến của 4 hệ thống bên dưới. Tuy nhiên, nếu bạn muốn mình gắn thêm code C# chi tiết từng dòng hàm cho các phần đó, bạn có thể gửi thêm các file sau:

  • 1. Assets/Scripts/Editor/StoryEventDirectorEditor.cs
    Script vẽ giao diện Custom Inspector tiếng Việt (nút "Tạo event", "Chỉ chạy một lần", "Tặng EXP", phần rút gọn "Nâng cao") trên StoryEventDirector.
  • 2. Assets/Scripts/AI/ZoneEnemySpawner.cs
    Component sinh quái tại Scene (Hiện đã có đủ 26 biến trong mục ZoneEnemySpawner ở cột trái từ file Excel).
  • 3. DemoNpcDialogueProfile.cs, DemoDialogueAsset.cs & DemoNpcDialogueController.cs
    Bộ 3 script Hội thoại (Hiện đã có đủ 32 biến trong mục DemoNpcDialogueProfile và DemoDialogueAsset ở cột trái).
  • 4. StoryLootChest.cs & StoryV2Benefits.cs
    Script rương đồ gọi On Opened Event Id và script kiểm tra quy tắc chế tạo đặc biệt (CraftMirror, CraftClaws...).
  • 5. PlayerProgressionService.cs & GameData.cs
    Cấu trúc file Save (PlayerSaveData, StoryCampaignSave, StoryPendingStep).
