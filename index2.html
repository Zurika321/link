Không thấy dữ liệu cũ

Trang này chỉ đọc được dữ liệu khi mở đúng địa chỉ web nơi bạn từng dùng bản cũ (ví dụ zurika321.github.io/index2.html) — không phải mở file tải về trên máy. Nếu bạn chắc chắn đang mở đúng chỗ mà vẫn thấy thông báo này, có thể trình duyệt đã bị xoá dữ liệu web trước đó.

Các bước tiếp theo

1Tải file .json ở trên về máy (hoặc AirDrop/gửi email cho chính mình nếu đổi thiết bị).
2Mở trang link phiên bản mới → nút vào Trang quản trị → mục Dữ liệu.
3Bấm Chọn file..., chọn đúng file .json vừa tải, chọn "Gộp vào dữ liệu hiện có" rồi bấm Nhập dữ liệu.
